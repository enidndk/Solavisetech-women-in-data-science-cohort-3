# Solavisetech-women-in-data-science-cohort-3

## About

SolaviseTech Women in Data Science is a learning program that helps women 
develop skills in Data Science, Machine Learning and Artificial intelligence.

## My Objectives

- Become comfortable with python and R.
- Understand Data science concepts.
- Understand the foundation of Machine learning and AI.
- Apply what I learn through hands-on exercises, assignments and projects.
- Learn how to approach problems logically and use data to develop meaningful solutions.
- Connect with other learners, learn from mentors and explore future opportunities in Data science.
- Build the confidence to explore new technologies and continue developing my skills beyond the program.
- Build a portfolio: Document my work and create projects that demonstrate my skills and progress.

## What I hope to achieve

I joined this program because I want to move beyond learning Data science in theory and start using what 
I learn to solve real problems. I know I'm still at the beginning of my journey, and I expect to encounter
challenge along the way. 

My goal is to finish this program with strong technical skills, practical projects I can explain confidently 
and a clear understanding of the kind of Data scientist I want to become.
